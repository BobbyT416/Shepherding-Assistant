SHEPHERDING ASSISTANT V2.4

Shepherding history:
- Completed calls do not disappear.
- Each publisher has a Shepherding History button.
- The button shows the number of completed visits.
- History is displayed newest first.
- Each entry shows date/time, brothers, type, and notes.
- Each history entry can be opened again to view or edit the original visit.
- Completing a call updates the publisher's last shepherding date.

Data remains local to this device/browser. Export a backup before transferring to another elder.
