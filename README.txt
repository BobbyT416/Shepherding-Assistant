SHEPHERDING ASSISTANT V2.33

Changes:
- Publishers are organized by household/family, with family heads first and names alphabetized within each family.
- Publisher records now include a Family Head checkbox.
- Publisher Role includes a blank option.
- Publisher records now include an Address field.
- A family head's address automatically populates the rest of the family; phone and email remain individual.
- Existing local data is migrated automatically with the new publisher fields.
- Previous V2.32 calendar and shepherding features are retained.

DATA:
The app continues to use the same local storage key. Export a backup before major updates.
