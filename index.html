Shared group: Checking group access…

Shared group data is stored in the group's cloud record. Loading replaces this device's current group data after confirmation. Saving uses version protection so a stale copy cannot overwrite another App Member's newer changes.

Transfer / Backup

Shared Cloud can automatically check for newer group changes and sync your completed changes when you are signed in with Full access. Use the backup options below for an independent copy of the group data.

For privacy, notes are excluded from backups unless the slider is turned on. Your notes on this device are never deleted by turning it off.

On iPhone/iPad, Save / Share Backup can use Save to Files. For importing from OneDrive or another cloud service on iPhone/iPad: open the Files app, tap Browse → OneDrive (or another location), find your backup, then use Copy or Move to place the backup in On My iPhone. Return here and tap Import Group Data to select it.

Local Storage

This app uses one fixed local data key. Keep using the same app folder/file when updating the program so the browser can retain its local data. The export backup is the safe way to move data to another elder's device.
